# Personal Expense & Budget Manager

A Python-based console application for managing personal expenses and tracking monthly budgets.

## Features

- Add expenses
- View all expenses
- Calculate total expenses
- Find highest expense
- View expenses by category
- Set monthly budget
- Check remaining budget
- Search expenses by category
- View expense statistics

## Technologies Used

- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements
- Basic Functions and Calculations

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
